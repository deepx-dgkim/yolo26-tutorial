DEEPX M1 NPU와 Raspberry Pi 5로 구축하는
초저전력 Edge AI 시스템

최근 엣지 AI(Edge AI) 기술의 발전으로 무거운 클라우드 서버를 거치지 않고도 기기 단에서 직접 복잡한 인공지능 모델을 실시간으로 처리하는 것이 가능해졌다. 하지만 제한된 전력과 발열, 그리고 임베디드 보드의 컴퓨팅 자원 한계는 여전히 엔지니어들이 풀어야 할 숙제다.

이번 특별 기고에서는 전 세계적으로 가장 널리 쓰이는 싱글 보드 컴퓨터인 'Raspberry Pi 5'와, DEEPX의 초저전력·고성능 AI 가속기인 'DX-M1 M.2 모듈'을 결합하여 강력한 엣지 AI 시스템을 구축하는 방법을 소개한다. 하드웨어의 아키텍처부터 시작해 야생동물을 인식하는 커스텀 모델 개발 및 포팅, 그리고 이를 활용한 실전 야생동물 감시 카메라 데모까지 엣지 AI 개발의 전체 워크플로우를 깊이 있게 파헤쳐 보자.

1. DEEPX NPU Introduction: 강력한 성능과 초저전력의 조화

HW 아키텍처 및 초저전력 설계

DEEPX의 DX-M1은 엣지 환경에 최적화된 25 TOPS (INT8 기준)의 연산 성능을 제공하는 AI 프로세서다. 단순히 TOPS 수치만 높은 것이 아니라, 실제 소비 전력 대비 추론 성능(Inference-per-Second/Watt)을 극대화하도록 설계된 것이 특징이다.

구체적인 전력 소모 지표를 보면 그 진가를 알 수 있다. 경량 객체 인식 모델인 YOLOv9T를 구동할 때의 전력 소모는 약 2.69W에 불과하며, 연산량이 훨씬 많은 무거운 모델인 YOLOv8L을 구동할 때조차 5.64W 수준의 매우 낮은 전력만을 소모한다. 이는 방열판이나 작은 쿨링팬만으로도 Raspberry Pi 5와 함께 운용하기에 완벽한 조건을 제공한다.

내부 블록 다이어그램 및 메모리 계층구조

DX-M1 chip 내부에는 Cortex M55 코어와 함께 3개의 NPU 코어(NPU0, NPU1, NPU2)가 탑재되어 병렬로 연산을 처리한다. 또한 고속 데이터 처리를 위해 LPDDR5 인터페이스를 지원하며 DX-M1 M.2 모듈에는 2G LPDDR 이 2개 장착되어 있고, PCIe Gen3 x4 레인을 통해 호스트 기기와 초고속으로 통신한다.

특히 주목할 점은 데이터 재사용(Data Reuse)을 극대화한 메모리 계층구조다. 딥러닝 모델의 특성상 메모리 대역폭이 병목 현상을 일으키기 쉬운데, DX-M1은 내부 SRAM과 최적화된 데이터 흐름 제어 설계를 통해 가중치(Weight)와 활성화(Activation) 데이터의 외부 메모리 접근 크기를 최소화한다.

2. DX-M1 M.2 NPU를 활용한 Raspberry Pi 5 의 Edge AI 시스템 탈바꿈

M.2 NPU 모듈 소개 및 HW 장착 방법

DEEPX DX-M1 M.2 모듈은 산업 표준인 M.2 2280 Key M 폼팩터를 채택하고 있다. Raspberry Pi 5는 공식적으로 PCIe 인터페이스를 지원하므로, NVMe HAT이나 M.2 확장 보드를 사용하면 이 NPU 모듈을 손쉽게 장착할 수 있다.

필수 SDK (DX-RT) 및 드라이버 간단 설치 방법

Raspberry Pi 5는 aarch64(ARM64) 아키텍처 기반의 운영체제를 사용한다. DEEPX의 런타임 소프트웨어인 DX-RT와 디바이스 드라이버는 aarch64 환경의 Ubuntu 및 Debian OS를 공식적으로 완벽하게 지원한다. Raspberry Pi default OS 인 debian 13 을 기준으로 DX-RT 및 NPU 드라이버 설치 방법은 아래와 같다.

# Install NPU driver
sudo apt update
wget https://github.com/DEEPX-AI/dx_rt_npu_linux_driver/raw/main/release/2.4.1/dxrt-driver-dkms_2.4.1-2_all.deb
sudo apt install ./dxrt-driver-dkms_2.4.1-2_all.deb

# Install libdxrt runtime
wget https://github.com/DEEPX-AI/dx_rt/raw/main/release/3.3.2/libdxrt_3.3.2_all.deb
sudo apt install ./libdxrt_3.3.2_all.deb

# Create dx-engine wheel
cd /usr/share/libdxrt/python_package && sudo ./make_whl.sh

# Install the bundled dx_engine Python wheel (Use python virtual env)
pip install dx_engine-*.whl

# Reboot the system
sudo reboot

만약 DX-M1 M.2 모듈의 F/W 버전이 낮으면 API 호환 이슈가 발생된다. 따라서 아래와 같이 NPU FW 를 upgrade 해 주면 된다. DX-RT v3.3.2 를 기준으로 NPU FW version 은 v2.5.6 이상이 권장된다.

# Upgrade NPU FW to v2.5.6
wget https://github.com/DEEPX-AI/dx_fw/raw//main/m1/2.5.6/mdot2/fw.bin
dxrt-cli -u fw.bin

설치가 잘 됐는지 검증하는 방법은 아래와 같다.

# Check the PCIe device status -> expected: 'Processing accelerators: DEEPX...'
spci | grep acc

# Check the PCIe generation and the number of lane for your NPU
# DX-M1 delivers the best performance on PCIe Gen3 (8GT/s), x4 lane
# Expected for Raspberry Pi 5 -> LnkSta: Speed 8GT/s, Width x1 (downgraded)
sudo lspci -vvv | grep -iA 33 accelerators | grep "LnkSta"

# Check NPU kernel driver status -> expected: dxrt_driver, dx_dma
lsmod | grep dxrt

# Check NPU device files -> expected: '/dev/dxrt0'
ls /dev/dxrt*

# Check NPU daemon status -> expected: dxrt.service - DX-RT Service is active (running) state
systemctl status dxrt.service

# Check the DX-RT and other version info -> expected: DXRT v3.3.2, FW v2.5.6
dxrt-cli -s

# Run a model as a quick validation -> expected: 'FPS: higher than 90'
wget https://sdk.deepx.ai/modelzoo/dxnn/2_3_0/yolo26n.dxnn
run_model -m yolo26n.dxnn -t 3 | grep FPS

PCIe 의 Speed 가 8GT/s 가 아니고 5GT/s 이면 Raspberry Pi 5 의 PCIe 가 gen3 가 아닌 gen2 로 설정된 상황이다. 아래 링크를 참조해서 gen3 로 변경해야 NPU 의 사용의 효율성을 높일 수 있다.

Raspberry Pi 5 의 PCIe 를 gen3 로 설정하기 (새 탭)

CLI 툴을 활용한 NPU 모니터링 실습

소프트웨어 설치가 완료되면, DEEPX가 제공하는 강력한 CLI 유틸리티를 통해 NPU의 상태를 확인할 수 있다. 가장 추천하는 모니터링 툴은 dxtop이다. 이 툴은 터미널에서 NPU의 실시간 상태를 직관적으로 보여주어, NPU 코어별 실시간 점유율, 온도, 전압, 동작 클럭뿐만 아니라 전용 메모리 사용량까지 한눈에 파악할 수 있다.

# CLI based NPU monitoring tool
dxtop

3. 크로스 플랫폼 개발: 커스텀 AI 모델 포팅 실전

이제 실제 현장에서 쓰일 법한 '야생동물 Detection 감시 카메라'를 구축해 보자. 개발 과정에서 혼동하지 말아야 할 개념은 컴파일 환경(Host)과 런타임 환경(Target)의 분리이다.

야생동물을 detection 하는 custom model 을 개발하는 과정과 실제 추론을 실행하는 시스템을 분리해서 생각해야 한다. AI 모델을 개발하고 DEEPX NPU 에서 동작하는 .dxnn 포멧으로 변환하기 까지의 과정은 별도의 성능이 좋은 시스템에서 수행하고, 실제 AI 모델을 가지고 추론을 실행하는 Edge Device (e.g., Raspberry Pi 5 + DX-M1 M.2 module) 에서는 DX-Runtime 위에서 동작되는 Applicaiton 을 개발해야 한다.

전체적인 AI Development Work Flow 를 설명하면 아래와 같이 5단계로 표현 할 수 있다.

  1. AI Use Case: YOLO26 모델을 사용해서 Object Detection 을 수행합니다.
  2. Data Preparation: Training 에 사용될 dataset 을 모으고 annotation 작업을 수행합니다. 자세한 내용은 4. 특별부록 을 참고하세요.
  3. Training: 확보한 dataset 을 가지고 야생동물을 detection 하는 YOLO26 모델을 training 을 통해 생성하는 과정입니다. 자세한 내용은 4. 특별부록 을 참고하세요.
  4. Optimization with DX-Compiler: Pre-trained 된 pytorch 기반의 weight 값을 ONNX 포멧으로 변환 후 DEEXP NPU 에서 사용 가능한 .dxnn 형식으로 변환하는 과정입니다. 4. 특별부록 에서 Ultralytics platform 을 통해 Cloud 에서 .dxnn 포멧으로 바로 export 하는 방법도 있으며, 여기에서는 Local PC 에서 DX-COM 을 사용해서 직접 compile 하는 방법을 설명합니다.
  5. Deployment: .dxnn 을 가지고 실제 DEEPX NPU 위에서 추론을 수행하는 Object Detection Applicaiton 만들어 보고 이를 실행시켜 봅니다.

[Host PC] 생성된 야생동물 Detection 모델을 DEEPX 에서 사용할 수 있게 dxnn 포멧으로 컴파일하기

DEEPX의 컴파일러인 DX-COM은 오직 x86_64 아키텍처의 PC 환경에서만 동작한다. 따라서 모델 학습과 바이너리 컴파일은 개발용 PC에서 진행하며 Debian 계열의 Linux system 을 권장하며 해당 시스템에 DX-M1 M.2 모듈이 꼭 필요한 사항은 아니다. Pytorch 등에서 학습된 weight 파일(pt) 에서 ONNX 포맷의 모델(예: YOLOv26s 등)을 추출한 뒤, DX-COM을 이용해 DEEPX 하드웨어 전용 바이너리 포맷인 .dxnn으로 변환한다.

  1. YOLO26s 로 pre-trained weight 다운로드: YOLO26s 모델을 기반으로 학습된 야생동물 YOLO26 모델의 weight 값을 다운로드 받습니다. yolo26s-wildlife.pt 파일이 다운로드 됩니다. https://drive.google.com/file/d/1bI6J_iye6U-MlRzuMsRyPUgV6FbUQKcT/view?usp=sharing.
  2. 필수 패키지 설치: 터미널이나 커맨드 창을 열고 python 가상환경을 생성 후 `pip` 명령어를 이용해 ultralytics 패키지를 설치합니다. 이 명령어 하나로 단 몇 분 안에 필요한 툴이 모두 설치됩니다. 
    # Python 가상환경 생성 및 활성화
python -m venv venv
source venv/bin/activate
pip install -U pip

# Install ultralytics & dx-com package
pip install ultralytics dx-com
  3. ONNX 변환 DX-Compiler 는 ONNX 로 1차 변환 이 이를 .dxnn 으로 변환 할 수 있습니다. ONNX 추출 시 반드시 batch size 를 1 로 고정해야 합니다. NPU 에서는 low latency 가 중요하기 때문에 multi batch size 를 고려하지 않고 1개의 고정된 batch 만 사용되도록 설계됐기 때문입니다. 
    # yolo export 명령어를 활용해 ONNX 포멧으로 추출 (input size = 640, batch size = 1)
yolo export model=yolo26s-wildlife.pt format=onnx batch=1 imgsz=640
    yolo26s-wildlife.pt 파일이 생성되면 성공이다. 그리고 추출된 ONNX 파일의 batch size 가 1 로 고정됐는지 https://netron.app. 을 통해 확인해 보자. 해당 브라우저에서 yolo26s-wildlife.onnx 파일을 로드하고 가장 상단의 images 레이어를 클릭해 input tensor shape 이 1x3x640x640 으로 보이면 된다.
  4. Calibration Data 준비: DX-Compiler 에서 FP32 to INT8 으로 Quantization 과정에서 사용될 calibration 용 이미지들이 필요하며 최소 100 장 이상을 권장합니다. 실제 input 에 사용되는 dataset 을 사용할 수록 accuracy loss 를 최소화 해서 dxnn 으로 변환 될 수 있습니다. 이번 과정에서는 임의 dataset 을 사용하나 실 사용에서는 반드시 실제 dataset 을 사용해 주세요. 
    # DX-Compiler 에서 FP32 to INT8 으로 Quantization 과정에서 사용될 calibration 용 이미지를 다운로드
wget "https://sdk.deepx.ai/dataset/calibration_dataset.tar.gz"
tar xzf calibration_dataset.tar.gz
  5. 컴파일 configuration 구성: 아래 내용으로 yolo26s-wildlife.json 파일을 생성해 주세요. 관련해서 자세한 내용은 DEEPX 개발자 페이지에서 DX-COM user manual 을 참고해 주세요. 해당 문서를 다운로드 받으려면 먼저 DEEPX 개발자 페이지에 계정을 생성하시고 로그인이 하셔야 합니다. https://developer.deepx.ai/download/?id=510 에서 다운로드 가능합니다.

  6. DX-COM 으로 컴파일 수행: 아래 내용으로 yolo26s-wildlife.json 파일을 생성해 주세요. 관련해서 자세한 내용은 DEEPX 개발자 페이지에서 DX-COM user manual 을 참고해 주세요. 해당 문서를 다운로드 받으려면 먼저 DEEPX 개발자 페이지에 계정을 생성하시고 로그인이 하셔야 합니다. https://developer.deepx.ai/download/?id=510 에서 다운로드 가능합니다.

    생성된 yolo26s-wildlife.dxnn 파일을 Target Device (Raspberry Pi 5) 로 카피한다. 만약 위 과정을 생략하고 바로 컴파일된 dxnn 파일만 받아서 다음 과정을 진행하시고 싶은 분은 다음 링크에서 컴파일된 야생동물 detection 기능을 하는 yolo26s-wildlife.dxnn 파일을 다운로드 가능합니다. https://drive.google.com/file/d/1qoW7jN7RhDYwCkla6GDB5p3aOfgQSUib/view?usp=sharing

[Raspberry Pi 5 Target] DX-APP 활용한 Custom YOLO26 Object Detection Application 구현

컴파일이 완료된 .dxnn 파일을 Raspberry Pi 5로 옮겨왔다면 추론을 실행할 차례다. DEEPX NPU 위에서 동작될 YOLO26 모델의 Application 을 만들기 위해서 가장 쉬운 접근방식은 DEEPX 에서 제공하는 Sample Code 를 수정하는 방식이다. DX-APP 에서는 DEEPX Model Zoo 에서 검증한 모든 AI 모델들에 대한 1:1 매칭되는 Sample Applicaiton 을 code 와 함께 제공하며 cpp, python 의 두 버전을 모두 지원한다.

DEEPX Model Zoo 를 보면 현재 DEEPX 에서 기 검증한 AI 모델들의 컴파일 전 ONNX 파일, 컴파일 된 dxnn 파일과 컴파일 configuration 파일 및 Sample Applicaiton code 를 제공하고 있으며 Sample Application code 들을 포함하고 있는 component 가 DX-APP 이다. https://developer.deepx.ai/modelzoo/ 에서 해당 사항을 확인 할 수 있다.

DX-APP 을 활용해서 손쉽게 내가 만든 YOLO26 모델의 Application 을 만들어 보자.

  1. DX-APP repository 내려받기: dx_app git repository 를 git clone 명령어를 통해 내려받습니다. 
    git clone https://github.com/DEEPX-AI/dx_app
cd dx_app

    # 스크립트 실행하면 아래와 같은 선택 메뉴가 나타난다.

4. 특별 부록: 나만의 YOLO26 커스텀 모델 학습 가이드

최신 객체 인식 모델인 YOLO26은 NMS(Non-Maximum Suppression) 후처리가 필요 없는 End-to-End 추론을 지원하며 엣지 디바이스 구동에 최적화된 차세대 비전 AI 모델입니다. 처음 해보는 사람도 손쉽게 자신만의 데이터셋을 구축하고 YOLO26 모델을 학습시킬 수 있도록 두 가지 방법을 소개합니다.

참고용 dataset 은 다음 링크에서 다운로드 가능합니다. 해당 dataset 은 IP 이슈로 약 30장의 소량의 data 만 포함하고 있으니 컨셉을 이해하기 위한 목적으로만 사용해 주세요. 실사용 목적의 정확도를 위해서는 최소 1000장 이상의 dataset 이 요구됩니다.

다운로드 링크: https://github.com/max5982/yolo26/raw/main/dataset/simple_wild_yolo.zip.

데이터셋 생성 및 파일/폴더 구조 배치

YOLO 모델을 학습하기 위해서는 이미지 파일 모음과 해당 이미지 안의 객체 위치(Bounding box)가 기록된 라벨 텍스트 파일이 필요합니다. Ultralytics 플랫폼과 모델은 YOLO, COCO, VOC 등 다양한 포맷을 폭넓게 지원합니다. 일반적인 커스텀 데이터셋의 폴더 구조는 아래와 같이 구성합니다.

dataset/
├── data.yaml          # 클래스 정보와 학습/검증 데이터 경로가 정의된 설정 파일
├── images/
│   ├── train/         # 모델 학습에 사용할 원본 이미지 (.jpg, .png 등)
│   └── val/           # 모델 검증에 사용할 이미지
└── labels/
    ├── train/         # 학습용 이미지와 동일한 이름의 라벨 텍스트 파일 (.txt)
    └── val/           # 검증용 라벨 텍스트 파일

5가지 class 의 야생동물을 정의한 custom 모델용 dataset 의 data.yaml 내부는 아래와 같이 정의됩니다.

# YOLO detection - 5 wildlife classes
path: simple_wild_yolo
train: images/train
val: images/val

names:
  0: water_deer
  1: wild_boar
  2: raccoon_dog
  3: asian_black_bear
  4: roe_deer

학습 방법 1: Ultralytics Platform 이용 (클라우드 환경, 초보자 추천)

코딩이나 별도의 PC 환경 설정 없이 웹 브라우저에서 편리하게 학습을 진행할 수 있는 방법입니다.

  1. 접속 및 데이터 업로드: https://platform.ultralytics.com 에 로그인하고 새 프로젝트를 생성하여 raw 이미지들을 업로드합니다.
  2. 스마트 라벨링 진행: 플랫폼에 내장된 SAM(Segment Anything Model) 기반의 스마트 어노테이션 도구를 사용하면, 클릭 한 번으로 바운딩 박스를 자동으로 생성할 수 있습니다. 이 기능을 활용하면 수동 작업 대비 최대 10배 빠르게 고품질 데이터셋을 완성할 수 있습니다.
  3. Cloud Training - New Model: 어노테이션 작업 완료 후, 플랫폼에서 제공하는 클라우드 GPU를 활용해 모델 학습을 바로 시작할 수 있습니다. 학습에 걸리는 며칠의 시간을 단축할 수 있으며, 정확도 등의 지표를 실시간으로 모니터링할 수 있습니다. New Model 을 선택합니다.
  4. Cloud Training - Base Model: 어떤 모델을 Base 로 Training 할 지 선정합니다.
  5. Cloud Training - Start Training: Cloud Training 은 과금 모델이며 약 1300장의 dataset 을 yolo26n 으로 training 시 $0.34 정도의 credit 이 소진됩니다. Account 생성 시 기업 email 로 가입하면 $25 free credits 가 부여됩니다.
  6. 내보내기: 학습이 끝난 완성된 프로덕션 레벨의 모델 파일을 Export 하면 yolo26n.dxnn 파일이 생성되며 이를 다운로드받아 NPU 에서 추론용으로 바로 사용 할 수 있습니다.

학습 방법 2: 내 로컬 PC에서 직접 학습하기

본인의 PC에 장착된 리소스를 활용하여 직접 커스텀 모델을 훈련하는 방법입니다. GPU 가 있는 환경을 권장하며 관련 개발환경이 기 설치된 시스템이란 가정하에 진행하겠습니다.

  1. 패키지 설치: 터미널이나 커맨드 창을 열고 python 가상환경을 생성 후 `pip` 명령어를 이용해 ultralytics 패키지를 설치합니다. 이 명령어 하나로 단 몇 분 안에 필요한 툴이 모두 설치됩니다.
